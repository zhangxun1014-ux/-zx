# Figma catalogue layout

Editable Figma file: https://www.figma.com/design/Ck47UccNYtx3VS9tHr9q2c

The `Catalogue Desktop` frame records the intended reading order and interaction
hierarchy: global navigation, catalogue title, search and category controls,
results, pagination, empty state and connection-error state. It uses Figma
auto-layout and a button instance from the Simple Design System library.

`figma-catalogue.png` is an export of that frame for insertion into the paper.
The final browser UI uses the same information structure with the project CSS.
